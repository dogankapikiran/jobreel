🔑 Instagram Token Güncelle

Token geçersiz veya süresi dolmuş olabilir. Aşağıdaki adımlarla yeni bir long-lived token oluşturup GitHub Secret'ı direkt güncelleyebilirsin.
Nasıl Yeni Token Alınır?
  1. Graph API Explorer'ı aç
  2. Uygulamanı seç (JobReel / jobreel)
  3. İzinleri ekle: instagram_basic instagram_content_publish pages_read_engagement
  4. "Generate Access Token" butonuna tıkla
  5. Oluşan token'ı kopyala ve aşağıya yapıştır
Token, libsodium ile şifrelenerek GitHub Secret olarak kaydedilir — düz metin olarak iletilmez.
